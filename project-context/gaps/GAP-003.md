# GAP-003 - Production Dependency Security Findings

Status: RESOLVED
Date: 2026-09-26

## Observation

WORK-007 dependency characterization found npm audit findings in the production dependency graph, not only in development tooling.

Full dependency tree:

- 15 total findings;
- 9 moderate;
- 6 high;
- 0 critical.

Production-only dependency tree (`npm audit --omit=dev`):

- 5 total findings;
- 2 moderate;
- 3 high;
- 0 critical.

Direct production dependencies reported as affected:

- `react-router-dom` - high severity;
- `fflate` - moderate severity.

Affected production transitive dependencies include:

- `react-router` - high severity;
- `nanoid` - high severity;
- `postcss` - moderate severity.

The full-tree audit additionally reports findings associated with development/tooling dependencies such as `firebase-tools`; those are not present in the production-only result.

## Interpretation

The npm audit result establishes dependency exposure but does not by itself prove that an advisory is reachable or exploitable through MindSpark.

Application-specific reachability, affected code paths, upgrade compatibility, and regression risk have not yet been assessed.

## Handling

Addressed by governed dependency-security work item `WORK-009`.

That work should:

1. capture exact installed and declared versions of each affected production dependency;
2. identify the underlying npm/GitHub advisories and vulnerable functionality;
3. determine whether affected paths are reachable in MindSpark;
4. prefer minimal non-breaking upgrades where available;
5. evaluate direct and transitive fixes separately;
6. avoid `npm audit fix --force` without explicit compatibility review;
7. run targeted regression tests and the complete `verify:web-release` gate after any dependency changes;
8. rerun both full-tree and production-only audits and record the residual findings.


## WORK-009 outcome

WORK-009 remediated the production dependency-security condition that defined this gap.

Production-only audit changed from:

- 5 findings;
- 2 moderate;
- 3 high;
- 0 critical;

to:

- 0 findings;
- 0 moderate;
- 0 high;
- 0 critical.

The full dependency tree changed from 15 findings (9 moderate / 6 high / 0 critical) to 5 findings (5 moderate / 0 high / 0 critical).

The remaining five moderate findings are confined to the current `firebase-tools` development/tooling graph. npm's available forced remediation would install `firebase-tools` 14.23.0 as a breaking downgrade, so that path was rejected under the WORK-009 compatibility and no-force constraints.

These residual development-tooling findings are explicitly characterized; they do not appear in `npm audit --omit=dev`.

All compatible non-major baseline remediation was applied, and the complete application, PWA, backup, routing, and local Firebase emulator regression gates passed.

GAP-003 is therefore RESOLVED.

WORK-009 was fast-forward promoted to canonical local `main` and canonically reverified. Production audit remained at 0 vulnerabilities; the full-tree audit remained at five characterized moderate `firebase-tools` development-tooling findings, with 0 high and 0 critical findings.

Canonical emulator/rules and web-release verification also passed, so the condition defining GAP-003 is closed.
